✅ Task 1.10: Streak Calculation Logic

Streak Algorithm (from PRD):

function updateStreak(habit) {
  const weeks = groupCompletionsByWeek(habit.completions);
  let currentStreak = 0;

  // Iterate weeks from most recent backwards
  for (let week of weeks.reverse()) {
    if (week.completions >= frequencyTarget) {
      currentStreak += week.completions.length;
    } else {
      break; // Streak breaks
    }
  }

  habit.currentStreak = currentStreak;
  habit.longestStreak = Math.max(longestStreak, currentStreak);
}

📊 Week Boundaries

Important: Weeks run Monday-Sunday (ISO 8601 standard)

The getWeekNumber() function uses ISO week numbering:
  • Week starts on Monday
  • Week 1 is the first week with a Thursday
  • Used for grouping completions by week
  • Ensures consistent streak calculations

🐛 Edge Cases Handled

  • No completions: Streak = 0, no errors
  • Current week in progress: Streak continues if past weeks met goal
  • Same day toggle: Can mark/unmark same day multiple times
  • Multiple habits: Each habit tracks independent streaks
  • Exceeding goal: If goal is 3/week but complete 5, streak = 5 (not 3)
  • Missing past weeks: Streak breaks even if weeks are skipped
